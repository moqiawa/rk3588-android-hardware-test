# RK3588 硬件测试程序设计

## 目标

为运行星光麒麟安卓兼容系统的 RK3588 设备构建一个独立的 Android APK。该程序对所有枚举到的摄像头、扬声器、麦克风输入和网络状态进行测试，并在本机保存测试证据和机器可读的测试报告。

## 范围与平台

- 使用 Kotlin、Gradle、Jetpack Compose 和 CameraX，与参考项目保持相同的构建工具链，并仅面向 `arm64-v8a` 架构。
- 最低支持 Android API 26，目标 API 35，编译 SDK 36，Java 17。
- 运行时仅请求 `CAMERA` 和 `RECORD_AUDIO` 权限。测试证据保存在应用专属外部媒体目录，不请求媒体库访问权限。
- 程序绝不修改设备系统音量。扬声器测试使用媒体音频流，实际播放音量始终跟随当前系统媒体音量。
- 程序只写入自身应用专属目录，不修改用户已有的媒体文件。

## 程序结构

首页为测试总览，分别提供摄像头、扬声器、麦克风、网络、设备与权限状态卡片。每张卡片显示状态（未测试、进行中、通过、警告、失败或需要权限）、简要结果和查看详情入口。

`TestCoordinator` 负责持有测试状态并串行调度硬件操作。`ReportStore` 负责保存带时间戳的 JSON 报告和测试证据引用。各硬件能力按职责拆分为平台服务，使报告序列化、音频测量、状态映射等逻辑可在没有 RK3588 实机时进行单元测试。

## 摄像头测试

摄像头服务通过 CameraX/Camera2 元数据查询每一个可用摄像头。界面按顺序列出每个摄像头的 ID、前后方向、支持的输出尺寸与测试结果。每个摄像头依次执行以下步骤：

1. 绑定预览和拍照用例到生命周期，并确认可以获得预览帧。
2. 在证据目录拍摄一张 JPEG，确认文件存在且大小大于零。
3. 录制一段 5 秒 MP4 视频（不录制声音），正常停止后确认文件存在且大小大于零。
4. 在测试下一路摄像头前解除当前摄像头绑定。

摄像头被占用、不可用、不支持录像、被取消或权限被拒绝时，将为该摄像头单独记录结果，并继续测试其余摄像头。自动判定基于可成功打开设备并获得有效媒体文件；操作人员还可查看实时预览和已保存证据，对画面质量作人工判断。

## 扬声器测试

扬声器服务读取并展示 `AudioManager.STREAM_MUSIC` 的当前音量和最大音量。它通过 `AudioTrack` 使用媒体用途/内容属性播放生成的 PCM 正弦测试音。初始化成功且播放位置持续推进即为通过；系统媒体音量为零时显示警告。程序不会调用任何设置音量的 API。

## 麦克风测试

麦克风服务枚举 `AudioManager.GET_DEVICES_INPUTS` 返回的全部输入设备。每个设备记录标识符、产品名称、类型、地址、是否为输入源、声道数、声道索引掩码、支持的采样率、编码格式，以及系统能够提供的麦克风位置/指向元数据。

录音测试使用受支持的单声道 PCM 配置和 `AudioRecord`，生成短 WAV 文件。程序逐帧分析 PCM 数据，报告录音时长、采样率、声道数、帧数、峰值 dBFS、均方根 dBFS、削波帧占比、近静音帧占比，以及是否检测到非静音输入。界面会明确说明：这些是可量化的信号质量指标，并非声学实验室级的频响或失真认证。

## 网络测试

网络服务通过 `ConnectivityManager` 读取默认网络和能力信息。它报告连接状态、传输类型（以太网、Wi-Fi、蜂窝网络、VPN 或其他）、已验证互联网能力、是否按流量计费、IP 地址、DNS 服务器和链路地址。另以带超时限制的 HTTPS 可达性请求补充系统能力结果；报告将明确区分“已接入局域网”和“已验证可访问互联网”，并记录超时或错误原因。

## 测试证据与报告

每次手动测试均有运行 ID 和时间戳。程序将 UTF-8 JSON 报告保存到应用外部文件目录，其中包含设备构建信息、权限状态、各项测试结果、详细测量值、错误信息和相对证据路径。测试证据包括 JPEG、MP4 和 WAV 文件。总览页支持复制报告内容；可用时可通过 Android 标准文档界面打开报告/证据目录。

## 错误处理与生命周期

耗时的采集、录制、分析和网络操作均不在主线程执行。界面销毁时会取消正在进行的工作，停止 `AudioTrack`/`AudioRecord`，并解绑 CameraX。执行某项测试前检查相应权限，权限缺失不会导致总览页崩溃。所有异常都会被转换为界面可见的结果，显示便于理解的说明，并在 JSON 报告中记录诊断异常类型。

## 验证策略

- JVM 单元测试覆盖报告序列化、麦克风 PCM 测量、扬声器音量判定、网络状态映射和摄像头测试状态流转。
- 构建过程执行 JVM 单元测试，并生成仅包含 `arm64-v8a` 的调试 APK。
- 在目标设备上进行人工验收：确认每个物理摄像头的预览/拍照/录像输出，确认当前系统音量下扬声器测试音可听见，确认对麦克风说话后可测得非静音输入，并确认实际网络连通性。

## 非目标

- 本程序不控制系统音量、不修改网络设置、不校准摄像头颜色/对焦，也不认证扬声器或麦克风的实验室级质量指标。
- 本程序不依赖 RKNN、NPU 模型、云服务或参考项目中的图像检索模块。
